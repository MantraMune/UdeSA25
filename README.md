*** Porfolio that contains all the work done during Autumn 2025 at UdeS in Computer Science ***

## IMN502 - Immersive environments and visualization
By using Unreal Engine, we learn how to create immersive environments (close to what we see in virtual reality) and to visualize 3-dimensional environments.

## IFT599 - Data Science
Using Python, we learn how unsupervised learning works in AI machine learning.

## IFT603 - Learning techniques
Using Python again (easier language to write all things related to AI), we learn how supervised learning works in AI machine learning.

## ART413 - Art and interactivity
A course mixing traditional art and electronics, we use Arduino kits to make interactive art pieces.
