# A25
*** Porfolio that contains all the work done during Autumn 2025 at UdeS in Computer Science ***

## IMN502 - Immersive environments and visualization
By using _Unreal Engine_, we learn how to create immersive environments (close to what we see in virtual reality) and to visualize 3-dimensional environments.

## IFT599 - Data Science
Using _Python_, we learn how unsupervised learning works in _AI_ machine learning.

## IFT603 - Learning techniques
Using _Python_ again (easier language to write all things related to _AI_), we learn how supervised learning works in _AI_ machine learning.

## ART413 - Art and interactivity
A course mixing traditional art and electronics, we use _Arduino_ kits to make interactive art pieces.
